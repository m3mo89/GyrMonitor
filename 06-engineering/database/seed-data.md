# Seed Data

Seed data supports development, testing and demos.

## Initial Development Seeds

- Admin user.
- Researcher user.
- Field operator user.
- System generator account.
- 100 sample cattle records.
- Sample activity events.
- Sample alerts with LOW, MEDIUM and HIGH severity.
- Sample observations.

## Rule

Seed data must never contain real farm, user or animal health data unless explicitly approved for the environment.
