# Phase 1: Foundation

## Goal

Prepare the project structure, tooling, conventions and baseline architecture before implementing business modules.

## Deliverables

- Repository structure.
- Backend NestJS skeleton.
- Frontend React + TypeScript skeleton.
- Mobile/Desktop .NET MAUI skeletons.
- Database project structure.
- Environment configuration strategy.
- Linting, formatting and testing baseline.
- Initial seed strategy.

Recommended change name:

setup-project-foundation

## Definition of Done

- Project builds successfully.
- Folder structure follows `06-engineering` and `07-reference` conventions.
- No domain logic is implemented yet.
- CI/test command placeholders exist.
- Documentation links remain valid.
