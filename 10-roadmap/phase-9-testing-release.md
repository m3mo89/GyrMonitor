# Phase 9: Testing and Release

## Goal

Stabilize the MVP for academic evaluation and future development.

## Scope

- Backend unit tests.
- Backend integration tests.
- Frontend component and integration tests.
- Offline sync test cases.
- Seed data validation.
- HTTP example validation.
- Documentation consistency review.
- Release checklist.

## OpenSpec Change

```text
stabilize-mvp-release
```

## Acceptance Criteria

- Main business flows are tested.
- API examples work against local backend.
- Offline sync scenarios are validated.
- README and roadmap reflect actual implementation.
- MVP scope remains free of automated detection pipelines, physical sensing infrastructure and specialized hardware deployment.
