# Proposal Checklist

Before approving a proposal:

- [ ] The problem is clearly stated.
- [ ] The affected domain module is identified.
- [ ] Related requirements are referenced.
- [ ] Related API contracts are referenced.
- [ ] Related ADRs are referenced when applicable.
- [ ] Offline behavior is considered when applicable.
- [ ] Security and roles are considered.
- [ ] The change is small enough to review.
- [ ] Out-of-scope items are explicit.
