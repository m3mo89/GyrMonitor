# OpenSpec Review Checklist

## Scope

- [ ] Proposal solves one clear problem.
- [ ] Proposal does not mix unrelated modules.

## Architecture

- [ ] Clean Architecture boundaries are respected.
- [ ] Domain logic remains technology-independent.

## Integration

- [ ] API impact is clear.
- [ ] Sync and idempotency impact is clear.

## Quality

- [ ] Test strategy is included.
- [ ] Risks and trade-offs are documented.
