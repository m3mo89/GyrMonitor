# Frontend Foundation

This folder contains the React + TypeScript frontend foundation for GyrMonitor.

Source guidance:

- `knowledge-base/06-engineering/frontend/overview.md`
- `knowledge-base/07-reference/directory-map.md`

The current scaffold provides Vite-oriented project metadata, app boundaries, feature folders, shared folders, and configuration placeholders. It does not implement authentication, dashboards, cattle views, events, alerts, metrics, or synchronization workflows.

## Commands

```sh
npm run build --workspace frontend
npm run lint --workspace frontend
npm run format:check --workspace frontend
npm run test --workspace frontend
```
