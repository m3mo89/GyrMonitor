# MVP Roadmap

This section defines the implementation roadmap for **GyrMonitor MVP**.

The MVP is a software platform for cattle management, activity event registration, alerts, observations, dashboard metrics and offline synchronization.

## MVP Phases

1. Foundation.
2. Authentication.
3. Cattle Management.
4. Observations.
5. Activity Events.
6. Alerts.
7. Dashboard.
8. Offline Sync.
9. Testing and Release.

## Explicitly Out of Scope

The MVP does not include automated detection pipelines, video processing, model inference, specialized hardware deployment, or external sensing infrastructure.

Structured events may be entered manually, generated by a simulator, or loaded from controlled test data.

## OpenSpec Starting Point

After this documentation baseline is approved, OpenSpec can begin with:

```text
add-authentication
```

Each proposal should be created manually and reviewed before implementation.
