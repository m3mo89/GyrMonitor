# OpenSpec Best Practices

## Keep Changes Small

Prefer several small proposals over one large proposal.

## Reference the Knowledge Base

Do not duplicate long requirements. Reference existing documents.

## Document Trade-offs

Every proposal should explain what is included, what is excluded and why.

## Do Not Skip Review

Even when using AI assistance, review the proposal manually before implementation.

## Update Documentation

When implementation changes behavior, update the Knowledge Base after the change.
