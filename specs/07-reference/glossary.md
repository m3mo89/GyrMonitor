# Developer Glossary

| Term | Definition |
|---|---|
| Activity Event | A recorded activity or inactivity event associated with a cattle entity. |
| Alert | Operational warning generated when risk exceeds a threshold. |
| Cattle | A Gyr bovine registered in the system. |
| Field Operator | User who reviews alerts and records observations in the field. |
| Idempotency-Key | Header used to avoid duplicate writes during retries. |
| Observation | Field note associated with an alert inspection. |
| Offline First | Design approach where mobile/desktop clients continue working without connectivity. |
| Risk Score | Numeric risk indicator calculated from inactivity behavior. |
| Severity | Qualitative risk classification: LOW, MEDIUM or HIGH. |
| Sync Queue | Local queue storing pending operations until connectivity is restored. |
| System Generator | System actor that registers activity/inactivity events. |
