# Definition of Done

A change is complete only when:

- [ ] The related requirement or proposal is clear.
- [ ] Implementation follows the documented architecture.
- [ ] Unit tests cover business rules or critical logic.
- [ ] Integration tests cover API behavior when applicable.
- [ ] DTOs and error responses match the reference.
- [ ] Role and security rules are respected.
- [ ] Offline and sync behavior is handled when applicable.
- [ ] Documentation is updated.
- [ ] Examples are updated when payloads change.
- [ ] The change can be explained from the Knowledge Base.
