# OpenSpec Naming Conventions

Use short, action-oriented names.

## Recommended Names

```text
add-authentication
add-cattle-monitoring
add-activity-events
add-alert-generation
add-observations
add-dashboard
add-offline-sync
```

## Avoid

```text
implementation-v1
backend-stuff
fix-all
new-system
```

## Rule

A change name should clearly describe one capability.
